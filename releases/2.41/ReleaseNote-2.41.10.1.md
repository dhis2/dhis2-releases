# Patch 41.10.1 Release Note

**Security hotfix release.** This release fixes six security vulnerabilities, including issues rated Critical and High. All of them can be triggered by ordinary logged-in accounts, and we strongly recommend that all instances upgrade as soon as possible.

Technical details are withheld at this time to allow administrators to patch. A confidential advisory has been distributed to designated security contacts, and CVE identifiers will be published later.

**Notable changes:** analytics table hooks and JasperReports-based report designs are disabled by default. If your instance uses either, see the full release announcement before re-enabling them.

See [Patch 41.10.0](ReleaseNote-2.41.10.md) for the full list of fixes included in the parent patch release.
